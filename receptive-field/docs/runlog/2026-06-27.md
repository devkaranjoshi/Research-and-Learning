## [Task 2] METHOD documented — how the ERF is measured

- **Date:** 2026-06-27
- **Goal today:** Write the experimentation method with full explanation so Task 2 is reproducible and the reasoning is explicit. (Doc task, no GPU.)
- **Method (summary):** ERF = **gradient ruler D**. For a (layer L, target t, window W) triple: embed tokens and set `requires_grad` on the EMBEDDINGS (ids are non-differentiable); forward with the SWA mask active (`config.sliding_window=W`, SDPA, bf16, weights frozen); take the residual-stream vector `h = hidden_states[L+1][t]`; backprop the SCALAR `‖h‖₂`; read `influence_j = ‖e.grad[j]‖₂` (L2 over d_model). Two defining choices: (C1) backprop from the residual-stream NORM at (L,t) = an into-this-layer RF, closest analog to the CNN center-unit probe; (C2) reduce input grad by L2 over d_model. Masked/future positions get EXACTLY zero gradient.
- **Metrics from the influence vector** (p_j = influence_j/Σ, d_j = t−j): mean lookback Σp_j·d_j; 90%-mass radius; threshold reach (>1% max); participation ratio 1/Σp_j² (eff #tokens); eff/theory = reach/((L+1)·W) = dilution ratio. Multiple metrics because threshold-reach saturates; the distribution captures dilution.
- **Dials (one at a time):** depth (layer); window (native 4096 vs imposed 512). Imposed small W = inference-time mask ablation on trained weights (D3) — needed because native W=4096 caps theory at seq len by layer 1, masking the depth-dilution.
- **Controls:** causality/window-severance (exact zeros, T3), attention-sink (`--mask-sink`; lesson 2026-06-25: never attribute influence to a position-0 token without a counterfactual).
- **Why compute setup doesn't bias result:** bf16/SDPA/frozen-weights/checkpointing change only speed/memory, not which tokens influence the unit or how much.
- **Caveats:** gradient (1st-order) ≠ attention weights ≠ full ablation; single prompt + last-token (not a corpus stat); bf16 noise floor ~1e-3; threshold-reach saturates at long native context.
- **Output:** `docs/TASK2_methodology.md` (9 sections: definition → procedure → metrics → dials → controls → compute → caveats → reproduce → summary).
- **What I learned:** Documenting forced the key distinction explicit: we measure an *into-layer residual* RF (C1), which is why it compares cleanly to the conv probe; a logit-target variant would measure a *behavioural* RF instead.
- **Next step:** Optional sink-control run + decay-length fit; or write TASK2_results.md consolidating the two dilution figures. GPU (GH200) can be released — method + headline results captured.

## [Task 2] SINK CONTROL — dilution finding robust; threshold-reach was a sink artifact

- **Date:** 2026-06-27
- **Goal today:** Confirm the position-0 attention sink isn't inflating the ERF/lookback metrics. Dial = sink on/off (`--mask-sink`), both W=512 and native W=4096.
- **Hypothesis:** H3 — sink present; distributional metrics should be robust to it; threshold-reach may be inflated by the far sink spike.
- **Experiment:** re-ran `mistral_erf.py` with `--mask-sink` (zeros influence at pos 0) for W=512/seq4000 and W=4096/seq8000; compared to un-masked baselines.
- **Actual outcome:** W=512: metrics IDENTICAL (only L31 90%-radius 1479→1478, rounding) — sink negligible there. Native W=4096: mean lookback / 90%-radius / participation ratio move <3% (robust), BUT threshold reach(1%) COLLAPSES at shallow layers: L4 7999→1293, L8 7999→4083 (L16+ stay ~7998). So the earlier "reach saturates by layer 4" was the pos-0 sink spike, not real influence.
- **Surprises:** Removing the sink REVEALED the genuine native depth-growth of effective reach (1293→4083→7998 over L4/8/16) that the sink had masked by pinning reach to 7999. The control killed a *metric* (threshold-reach), not the *finding* (dilution).
- **What failed:** threshold-reach(1%) as a standalone metric — sink-contaminated at shallow layers in the native case. Use mass-weighted metrics instead (as already noted in methodology §3).
- **What I learned:** The dilution headline (effective field ~500 tokens, mean lookback ~3.3k « 8000 reachable « 131k theoretical) is sink-robust. The gradient is causally correct (sink truly influences) but its single far spike inflates max-relative metrics while barely moving mass-weighted ones — exactly why distributional metrics + the sink control are both required (2026-06-25 lesson applied and paid off).
